# List

> List brukes for å presentere innhold på en oversiktlig og strukturert måte, for eksempel for å oppsummere hovedpunkter eller vise brukeren hvilke trinn som må følges i en bestemt rekkefølge.

> Se full dokumentasjon for komponenten på [designsystemet.no](https://designsystemet.no/no/components/docs/list/overview)

## Kode

- Bruk `<List>` komponenten i React
- Bruk `List.Unordered` for usortert liste
