# Badge

> Badge er en ikke-interaktiv komponent som viser status med eller uten innhold. Bruk Tag dersom du skal ha tekst istedenfor tall.

> Se full dokumentasjon for komponenten på [designsystemet.no](https://designsystemet.no/no/components/docs/badge/overview)

## Kode

- Bruk `<Badge>` komponenten i React
- Bruk `count` for antall og `maxCount` for øvre grense visning
- Utelat `count` for badge uten tall

<Canvas of={stories.Default} />

- Bruk `data-color` for å endre farge
