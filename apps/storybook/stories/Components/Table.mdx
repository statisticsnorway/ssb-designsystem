# Table

> Table brukes for å vise strukturert informasjon på en ryddig og oversiktlig måte. Tabeller kan gjøre det enklere for brukerne å skanne og sammenligne informasjon.

> Se full dokumentasjon for komponenten på [designsystemet.no](https://designsystemet.no/no/components/docs/table/overview)

## Kode

- Bruk `<Table>` komponenten i React

<Canvas of={stories.Default} />

## Zebra-striper

- Bruk `zebra` for å gjøre tabellen lettere å lese ved å skille radene visuelt.

<Canvas of={stories.Zebra} />

## Med ramme

- Bruk `border` for å hjelpe brukerne med å skille tabellen fra annet innhold på siden.

<Canvas of={stories.Border} />

## Hover

- Bruk `hover` for å vise en hover-effekt på tabellradene.

<Canvas of={stories.Hover} />
