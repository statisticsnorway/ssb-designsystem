# Universell utforming

> Designsystemet tilbyr grunnleggende komponenter som bidrar til å ivareta [WCAG-kravene som inngår i regelverket for universell utforming](https://www.uutilsynet.no/wcag-standarden/wcag-standarden/86). Hvor godt kravene ivaretas, avhenger også av hvordan komponentene brukes og hvordan innholdet utformes.

<div className='universell-utforming-lists'>
    <Alert data-color="success">
        <Heading as="h3">Dette løser designsystemet:</Heading>
        <ul>
            <li>**Fokustilstander:** Tydelige og synlige fokustilstander for interaktive elementer på alle bakgrunner.</li>
            <li>**Fargekontrast:** Tilstrekkelig kontrast og form på innhold for både svaksynte og fargeblinde.</li>
            <li>**Tastaturtilgjengelighet:** Alle interaktive elementer kan nås og betjenes med tastatur.</li>
            <li>**Skalerbart design:** Tilpasning til forskjellige skjermstørrelser, zoom og foretrukket tekststørrelse.</li>
            <li>**Rolle og tilstand:** Støtte hjelpeteknologi med semantikk og ARIA-attributter.</li>
            <li>**Tilgjengelige skjema:** Korrekt struktur, sammenknytting og validering.</li>
            <li>**Interaktiv elementstørrelse:** Tilstrekkelig berøringsflate basert på WCAG 2.2-kriteriet 2.5.8, som er veiledning utover dagens lovpålagte WCAG 2.1-krav.</li>
        </ul>
    </Alert>
    <Alert data-color="info">
        <Heading as="h3">Dette må du sørge for:</Heading>
        <ul>
            <li>**Semantisk HTML:** Bruk passende elementer for å formidle riktig rolle og overskriftshierarki.</li>
            <li>**Tekstalternativer:** Bruk passende tekstalternativer for ikke-tekstlig innhold. Kravene er dokumentert på de enkelte komponentsidene.</li>
            <li>**Spesifiser innholdsspråk:** Angi riktig språkkode for siden, for eksempel `<html lang="no">` for norsk.</li>
            <li>**Fargemodus (valgfritt):** Bruk `<body data-color-scheme="auto">` for å følge brukerens systempreferanser.</li>
            <li>**Korrekt token-bruk:** Dersom en token heter `border` - bruk den til border og ikke background, osv.</li>
        </ul>
    </Alert>
</div>
